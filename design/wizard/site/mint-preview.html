Step 1 of 4 · Mint

Mint a plugin

Minting creates a new, empty plugin in this repository: a Rust crate for its code and a manifest that says what it claims. Nothing is fetched and no wiki changes.

Lowercase letters, digits and hyphens. Used for the crate and folder names.

What readers and authors see.

A fenced code block belongs to this plugin when its info string has this key, as in ```bash variant=macOS.

Consecutive claimed blocks with the same value of this key are rendered as one.

Profiles

Plain HTML with no script, so BerryWiki can serve it. Every plugin must work here first.

Adds script on top of the static result, for hosts that allow it. Readers without script still get the static result.

Must be compatible with MPL-2.0.

Preview: what minting will create

Four new files. Nothing existing changes. The plugin's ID is derived from its name, so minting the same name again gives the same ID.

  • createplugins/progblocks/progblocks.plugin_praxis.deed · manifest
  • createcrates/berry-blocks-progblocks/Cargo.toml
  • createcrates/berry-blocks-progblocks/src/lib.rs · a Block that claims nothing until you write it
  • createcrates/berry-blocks-progblocks/tests/conformance.rs · BerryWiki pages must stay byte-identical
  • modifyCargo.toml · adds the crate to the workspace
